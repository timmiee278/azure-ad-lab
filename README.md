# Azure Active Directory Lab

## Project Overview
This project demonstrates a simulated enterprise IT environment using Microsoft Azure Virtual Machines and Windows Server.

## What I built so far
- Created Azure Virtual Machine
- Installed Windows Server
- Configured Active Directory Domain (itlab.local)
- Created users and groups (e.g. jcastro)
- Configured Group Policy (IT-Policy)
- Tested Remote Desktop access

## Skills Practiced
- Windows Server Administration
- Active Directory (AD DS)
- Group Policy Management
- Remote Desktop Services (RDP)
- Basic IT troubleshooting
