# Azure Active Directory + Windows Server Lab

## Project Overview
This project demonstrates a complete Active Directory environment built using Microsoft Azure Virtual Machines. It simulates a real enterprise IT setup for identity management, access control, and system administration practice.

## Environment Setup
- Microsoft Azure Virtual Machine
- Windows Server (Domain Controller)
- Domain: itlab.local

## Configurations Completed
- Installed Active Directory Domain Services (AD DS)
- Created domain users (e.g. jcastro)
- Configured Organizational Units (OU)
- Created and applied Group Policy (IT-Policy)
- Configured Remote Desktop access (RDP)
- Tested user login and access restrictions

## Group Policy (IT-Policy)
- Restricted Control Panel access for selected users
- Configured RDP permissions
- Applied policies to domain users via OU

## Skills Demonstrated
- Windows Server Administration
- Active Directory Management
- Group Policy Configuration
- Remote Desktop Services (RDP)
- IT troubleshooting and access control
